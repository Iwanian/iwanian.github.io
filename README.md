# Iwana (نسخهٔ GitHub Pages)

در این نسخه سایت عمومی فقط پوشهٔ `docs/` است و هیچ کد، لینک یا فایلی از پنل مدیریت ندارد. پنل یک فایل جدا (`iwana-admin.html`) است که فقط روی کامپیوتر خودتان می‌ماند و با توکن GitHub روی همین ریپو کامیت می‌کند.

## راه‌اندازی

1. **ریپو بسازید** و محتوای این پوشه را در آن بگذارید (`docs/`، `README.md`، `.gitignore`).
   - Pages برای ریپوی **پرایوت** فقط در پلن‌های پولی GitHub فعال می‌شود. در حساب رایگان ریپو باید public باشد. (پس از انتشار، `docs/data/content.json` هم برای همه قابل دیدن است. این همان محتوایی است که روی سایت دیده می‌شود.)
2. در ریپو: **Settings ← Pages ← Build and deployment**: Source را روی *Deploy from a branch* بگذارید، شاخه `main` و پوشه `/docs`.
3. بعد از یکی دو دقیقه سایت روی `https://<نام‌کاربری>.github.io/<نام‌ریپو>/` بالا می‌آید.

## توکن برای پنل
1. GitHub ← Settings ← Developer settings ← Personal access tokens ← **Fine-grained tokens** ← Generate new token.
2. Repository access: **Only select repositories** و فقط همین ریپو.
3. Permissions ← Repository permissions ← **Contents: Read and write**.
4. مدت اعتبار را کوتاه بگذارید (مثلاً ۹۰ روز). توکن را فقط خودتان داشته باشید.

## استفاده از پنل
فایل `iwana-admin.html` را روی کامپیوتر خود با مرورگر باز کنید (دابل‌کلیک). ریپو (`نام/ریپو`)، شاخه (`main`)، پوشهٔ سایت (`docs`) و توکن را بدهید.
- افزودن، ویرایش، حذف و جابه‌جایی برنامه‌ها و پروژه‌ها
- آپلود فایل نصبی برای هر سیستم‌عامل (تا ۲۵ مگابایت؛ SHA-256 خودکار محاسبه می‌شود)
- هر ذخیره یک کامیت است و Pages یکی دو دقیقه بعد سایت را به‌روز می‌کند.

این فایل را در ریپو نگذارید و جایی آپلود نکنید. فقط با `api.github.com` ارتباط می‌گیرد.

## فایل‌های بزرگ
GitHub فایل بالای ۱۰۰ مگابایت را در ریپو قبول نمی‌کند. فایل بزرگ را در **Releases** ریپو آپلود کنید و لینک آن را در پنل، در «لینک صفحهٔ رسمی» همان برنامه بگذارید.

## نکته‌ها
- `docs/data/content.json` تنها جایی است که محتوا در آن ذخیره می‌شود. از آن بک‌آپ لازم نیست؛ تاریخچهٔ کامیت‌ها همین کار را می‌کند.
- اگر دو جا همزمان ویرایش کنید، پنل ذخیرهٔ دوم را رد می‌کند و می‌گوید صفحه را بازخوانی کنید.
- دامنهٔ دلخواه: در Settings ← Pages ← Custom domain. سایت از مسیرهای نسبی استفاده می‌کند و روی هر دو حالت کار می‌کند.
